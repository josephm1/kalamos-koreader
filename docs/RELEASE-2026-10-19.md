# Kalamos KOReader: Android preview, 19 October 2026

Release tag: `v2026.10.19-preview.1`. ARM64 tablet builds; Notes and KOReader require Android10+;
Agora requires Android8+. These are developer/debug-signed previews, not store-signed upstream releases.
An existing installation signed with another key cannot be updated in place. Back up local data
before changing application variants or installations. No on-device testing was performed for this
release packaging; physical pen/panel testing belongs to the owner.

## Build and source

Build the pinned upstream repositories recorded in `integrations/review/upstream.lock.json`, with their submodules.
Use `KALAMOS_DEVICE=standard ./integrations/koreader/build.sh /path/to/koreader`, or `KALAMOS_DEVICE=bigme`.
Then in the prepared upstream checkout: `GRADLE_FLAGS='-PkalamosInk=true -PkalamosDevice=standard' ./kodev build android-arm64 --debug`
and `GRADLE_FLAGS='-PkalamosInk=true -PkalamosDevice=standard' make TARGET=android-arm64 KODEBUG=1 update`.
For Bigme, use `-PkalamosDevice=bigme` in both commands. Save each resulting APK before switching provider.
The source preparation includes the Android GLib runtime-path patch, so host staging paths are not embedded in sdcv.
It packages copyright/licence notices under assets/kalamos-notices/, outside upstream's compressed-asset licence exclusions.
Both APKs use `org.koreader.launcher.debug`; install one variant. The handwriting plugin is already bundled.
The optional TOC-sharing ZIP works on stock Android KOReader too; do not install duplicate bundled plugins.
The source bundle supplies pinned upstream Git sources/submodules, third-party download archives, integration changes and build instructions.
Use the documented Git clones when building to retain upstream version metadata; GitHub's automatic integration-only source ZIP is not the full reader.

Release assets include APKs, a matching source archive, component licence notices and SHA256SUMS.txt.
Signing private keys, notebooks, API credentials and local build configuration are excluded.
